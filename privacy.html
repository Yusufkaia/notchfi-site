Privacy Policy

Effective October 10, 2026 · Applies to NotchFi for macOS

Summary

NotchFi does not collect, sell or share personal data. There is no account, no analytics and no advertising. Everything NotchFi measures stays on your Mac.

Data stored on your Mac

  • Settings — your preferences, such as island options and your data plan.
  • Data usage history — daily byte counts per network, used for usage totals and plan warnings, and the result of your last speed test per network.

This data is kept only inside NotchFi's sandboxed container on your Mac and is never uploaded. Deleting NotchFi removes it.

Network requests

NotchFi talks to two services, only for the features below. These requests carry no account, device identifier or personal information; like any internet request, they reveal your public IP address to the service that answers them.

  • Cloudflare (speed.cloudflare.com) — when you run a speed test, NotchFi downloads and uploads test data. When you connect to a network, NotchFi makes an empty request whose response tells it which network operator (ASN) serves your connection. See Cloudflare's privacy policy.
  • RIPE NCC (stat.ripe.net) — NotchFi looks up the public name of that network operator, for example "Turkcell", in the RIPE NCC registry. See RIPEstat terms.

You can turn off the carrier name lookup in NotchFi > Settings > Privacy. Speed tests run only when you start them.

Permissions

  • Location (optional) — macOS reveals the name of your Wi-Fi network only to apps with Location access. NotchFi uses it solely to show that name; it never reads, stores or shares your location.
  • Notifications (optional) — requested only if you turn on data plan warnings.
  • Launch at login (optional) — off unless you turn it on.

Children

NotchFi does not collect personal information from anyone, including children.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
